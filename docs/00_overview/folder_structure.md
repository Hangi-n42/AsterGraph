# 현재 폴더 구성

`app/knowledge/`: 지식 코어 / `app/api/`: 지식 API와 공통 오류 / `app/generation/`: 모델·용량 / `app/retrieval/`: 공용 검색 / `frontend/`: 지식 화면 / `app/tests/`: 지식·공용 검사.

`configs/knowledge/`, `docs/05_plans/company_knowledge/`, `docs/70_research/company_knowledge/`는 지식 설정·계획·실험 기록입니다. `data/knowledge`의 실제 DB·원문·실행 결과는 로컬 보존 자료입니다. 민원 전용 폴더는 독립 민원 저장소로 분리했습니다.

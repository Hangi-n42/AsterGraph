## 비교 목적과 변경

다음 비교의 C는 `hybrid_graph`를 명시하는 **C_v2**로 정의한다. 목적은 같은 원문에서 기존 Hybrid 검색에 현재 개념 그래프 검색 경로를 추가했을 때 필요한 근거·답변·비용이 어떻게 달라지는지 확인하는 것이다. 과거 C의 6문항 결과를 새 C의 결과로 재표기하지 않는다.

| 구분 | 검색 경로 | 제품 요청 |
|---|---|---|
| B | BM25 + 문서 임베딩 → RRF | `retrieval="hybrid"` |
| C_v1, 과거 기록 | 관계 선택 + 문서 임베딩을 이용한 그래프 PPR | `retrieval="hipporag2", graph_variant="full"` |
| C_v2, 다음 비교 | B의 Hybrid 순위 + 기존 그래프 PPR 순위 → RRF | `retrieval="hybrid_graph", graph_variant="full"` |

새 C가 무조건 더 정확하다는 가정은 없다. 이는 비교 목적을 맞추는 변경이다. 그래프 관계 선택 모델·전파·순위 결합 전체의 추가 효과를 측정하며, 연결 구조 하나의 순수 효과로 해석하지 않는다.

## 실제 동작

1. 동일한 전체 원문 풀과 제목·표·참조 문맥으로 BM25와 문서 임베딩 순위를 만든다. 추출된 관계가 없는 원문도 포함한다.
2. B와 같은 `RRFFusionStage`, `k=60`을 사용해 Hybrid 순위를 만든다.
3. 기존 C의 관계 후보 상위 30개 선택, 노드 seed 상위 10개, PPR 설정을 그대로 사용한다.
4. Hybrid와 그래프 순위를 동등한 두 순위 입력으로 RRF 결합한다. 그 뒤 기존 공통 문맥 선택과 동일한 답변 경로를 사용한다.
5. 선택된 graph seed가 없으면 B의 순위와 점수를 그대로 반환하고 `fallback="hybrid_passages"`, `graph_used=false`를 기록한다. 관계 선택 호출 실패는 fallback으로 숨기지 않고 기존 검색 실패로 처리한다.

수식은 `H(d)=1/(60+r_BM25(d))+1/(60+r_dense(d))`,
`C_v2(d)=1/(60+r_H(d))+1/(60+r_graph(d))`이다. 없는 순위의 기여는 0이다.
그래프 순위 자체에도 문서 임베딩이 들어가므로 두 입력은 독립 신호가 아니다. 별도 dense 순위를 세 번째 입력으로 더하지 않는다. 이 결합·상수의 최적성은 미확인이다.

저장 trace는 BM25·dense·Hybrid·graph·최종 순위, 선택 관계, seed, fallback을 구분한다. seed가 있다는 사실은 전파 실행을 의미하며, 유용한 순위 변화나 올바른 근거 확보를 보장하지 않는다.

## 제품 진입점과 비교 조건

기존 `POST /api/v1/knowledge/business/search`에 다음 요청을 사용한다. `source_run_id`와 질문은 다음 비교에서 고정한 실제 값으로 채운다.

```json
{
  "source_run_id": "<고정한 원문 추출 실행 ID>",
  "question": "<변경하지 않은 질문>",
  "retrieval": "hybrid_graph",
  "graph_variant": "full",
  "limit": 12,
  "source_context_tokens": 16384
```

B는 같은 요청에서 `retrieval`만 `hybrid`로 바꾼다. 서비스 직접 호출 시 B는 `context_mode="document"`, C_v2는 `context_mode="graph"`를 사용한다. 승인 snapshot 경로·UI 기본값은 이번 원문 검색 비교와 분리해 기존 값을 유지한다. 기존 동결 실행기를 그대로 돌리면 과거 `hipporag2`가 실행되므로, 다음 실행 manifest에서 **C_v2와 `hybrid_graph`를 명시**해야 한다. 과거 순위를 강제로 재사용하는 P2/P3/P4 runner는 새 검색 검증에 사용하지 않는다.

원문·자동 그래프 snapshot·질문·임베딩·답변 모델·공통 문맥 처리·최종 입력 한도를 동일하게 고정한다. 그래프나 질문을 정답에 맞춰 보완하거나 필수 정답 근거를 강제 삽입하지 않는다. 과거 C를 추가로 재실행하는 것은 항상 필수가 아니며, 동일 조건의 저장 응답만 재사용한다.

# 실제 RAG 후속: 근거 재선택과 원문 배열 비교

2026-10-13 · 기존 #660의 제한 후속 · 개발에 노출된 고정 사례

**B는 문서 Hybrid 검색, C는 개념을 포함한 그래프 검색이다.** 두 arm은 동일한 원문 풀과 QA 설정을 사용했다.

**P3의 고정 listwise 선택 방식은 미채택했다. P4의 원문 배열은 1개 개선·5개 동일·1개 부분 회귀를 보였으며 기본 경로와 제품 opt-in 채택을 모두 보류했다. 두 후보는 동결 연구 코드로만 보존한다.** 제품 파일 3개와 시험 파일 2개은 시작 HEAD `ade0185c`와 완전히 같으며 이전에 채택한 P2 위치 복원은 유지했다. 일부 효과를 없던 것으로 처리하거나 방법 전체가 불가능하다고 결론짓지 않는다.

## 이 범위를 선택한 이유

ACT501070은 필요한 생산설비·일반 운전자금 원문이 검색 후보에 있었지만 최종12개 선택 밖이었다. SUP02 C는 예외를 설명하고도 같은 답변에서 ‘확인 불가’와 ‘제외’를 함께 말했다. 검색의 근거 전달과 답변의 조건 적용을 분리해 비교했으며 전체 추출·새 임베딩·외부 모델·학습을 확대하지 않았다. [실행 전 계획](document_graph_rag_followup_20261012_plan.md)의 기준과 중단 조건을 유지했다.

동일 source run `185606e5f6604e9c9d969aa16b539170`, 원문 3,364개 블록과 검색 구간 3,371개, 부분 그래프·기존 벡터·원질문·B/C 원순위를 고정했다. 모델은 `qwen3.8:27b-q4_K_M`, digest `25b843619e944cd0ae6069f94ff4e5e26a16e109ccbc0a66a0f05979ed70098e`다. context 49,152 / output 4,096, T0, think=false, timeout1800초, 재시도 0, 선택 12개와 source 예산 추정 상한 16,384를 유지했다.

## P3: 회수 성과와 답변 회귀를 분리

원질문 전체를 유지하고 기존 상위 `5*limit=60` 후보의 완전한 본문·필수 문맥에서 관련성·요청 포괄에 필요한 ID만 선택했다. 기존 `json_call/ModelClient`를 사용했고 600자 clipping, 정답 ID 강제, 자금별 할당, 새 의미 판정층은 넣지 않았다. 이유 문장은 답변 근거로 전달하지 않았다.

선택 2회 뒤, 이전 ACT 결과에 없던 P2 위치 복원의 영향을 통제하기 위해 현재 코드의 원선택 기준선 B/C를 새로 실행했다. 선택기 응답은 해당 QA에서 정확히 재사용했다. 검색 근거 도달과 답변의 의미를 같은 성공으로 합산하지 않았다.

| 확인 경계 | 실제 관찰 | 판정 |
|---|---|---|
| 생산설비 P397·일반 운전자금 P412 | B/C 모두 선택과 실제 QA 입력에 도달 | 제한 회수 성과 |
| 다른 자금의 대상 조건 | 혁신창업지원·7년 미만 조건이 새 선택에서 사라짐 | 다른 자금 안내의 조건 누락 |
| 자격①/② | 현재 원선택 B의 대안 경로 판단이 새 B에서 ‘둘 다 필요’로 바뀜. C도 동시 충족 오류 유지 | 중대한 의미 회귀 |
| 두 번째 요청 | B는 시설·일반 운전자금 용도를 사용했지만 다른 자금을 조건과 연결하지 못함. C는 근거를 받고도 개발기술 자금만 다시 안내 | 요청 전체 미충족 |

현재 기준선 자체에도 특허 보유와 실제 사업화의 구분, 금리 예외·대안 안내 문제가 남았다. 기준선을 완전한 정답으로 취급하지 않았다. 선택된 입력에는 양산 후 3년 제외·업력 무관 원문이 전달됐으나 답변의 조건 보존은 별도 실패 경계다. P3 정상 대조 6건은 모델 없이 준비만 했으며 추가 실행·quota 조정·결합 비교는 하지 않았다.

## P4: 손실 없는 배열도 의미 보존을 보장하지 않음

기존 선택 `context`와 필수 `source_context`의 기록을 source version·parse·native block order·span·경로순으로 함께 배치했다. 인덱스 배열로 두 원배열을 정확히 재구성했다. 모든 본문·주소·조건·표 정보, 선택 집합, 출력 schema와 답변 필드 순서는 유지했다. 바뀐 system 문장은 bundle을 읽고 인용하는 기계적 형식 안내뿐이다. 의미 강화 지시나 정답 해석을 추가하지 않았다.

| 질문·arm | 기준선 → P4 | 실제 의미 |
|---|---|---|
| SUP02 C | 부분 → 충족 | 청년전용창업자금 식별과 특허 매입 **투자자금 용도** 제외를 일치시킴. 확인 불가/제외 모순 제거 |
| SUP02 B | 충족 → 충족 | 같은 투자자금 제외 유지. 시설 전체·모든 특허지출 금지로 확대하지 않음 |
| SUP01 B/C | 충족 → 충족 | 개발기술사업화자금 식별 및 임차보증금 제외 유지 |
| SUP03 B/C | 충족 → 충족 | 연 2.0% 고정금리 유지 |
| ACT501108 B | 충족 → 부분 | 법률상 창업자 요건과 개별 창업 인정의 확인 불가는 유지. 기준선의 7년 미만 업력 조건은 누락 |
| ACT501108 C | 비교 미실행 | 현재 native 위치 기준선의 source 예산 추정 17,705가 상한 16,384를 초과. QA 0회 |

ACT501108 B의 기준선은 개시일이 7년 안이라는 기간 조건과 기존 공장 사용의 법적 창업 인정을 구분했다. P4는 후자의 자료 공백을 지켰으나 전자를 답변에서 빠뜨렸다. 실제 P4 송신 입력의 선택 원문 **q7**에는 혁신창업지원의 ‘사업 개시일로부터 7년 미만’ 조건이 완전히 있었다. 이 회귀는 검색 누락이 아니라 확보한 원문의 **답변 누락**이다. 공백을 함부로 채우지 않았다는 사실만으로 요구 전체 충족으로 채점하지 않았다. C는 필수 문맥 삭제·한도 확대·이전의 작은 입력 교체로 통과시키지 않았다. P4 C 자체의 입력 예산은 이 비교에서 확인하지 않았다.

동일 정보를 배치하고 형식 안내를 바꾸어 한 모순을 해소한 성과는 인정한다. 그러나 사용자가 유리한 질문과 필수 조건이 누락될 질문을 미리 구분할 근거는 없다. 제품에 입력 형식 옵션을 남기면 이 선택과 두 경로의 유지 부담을 추가한다. 확인된 가치가 이를 뒷받침하지 않아 연구 코드로만 보존했다. 결과별 사후 라우팅이나 작은 표본100% 기준으로 일반 가능성을 기각하지 않았다. 조정자가 고정 원문 참조와 실제 raw를 직접 대조해 최종 판정했다.

## 검증과 보존

- 실제 prototype 경계 검사 33개 통과(6.85초). P3 제거 직후 P4 경계 검사 28개 통과(7.94초), 동결 요청 8개와 실제 제품 입력의 정확 재생 확인·모델 0회. 이 검사는 입력/코드 계약이며 의미 정확도 증거가 아니다.
- P4도 제거한 최종 제품 파일 3개와 시험 파일 2개은 `ade0185c`와 byte 동일하다. 변경 없는 제품 검사나 의미 모델 호출을 반복하지 않았다. 연구 patch는 임시 기준 파일 5개에 적용해 동결 코드 파일 5개을 정확히 재구성했다.
- 원본 DB·pool·질문·설정·cache·기존 QA 등 16개 파일의 SHA-256 동일. 실제 호출은 별도 DB 사본에서 수행했고 원형 입력/응답을 덮어쓰지 않았다.
- P3 준비 V1은 budget이 아직 DB에 저장되지 않은 capture 단계에서 해당 필드를 읽어 오류가 났다. 저장된 B 요청에서 계약을 복구했고 B 준비·모델 재실행 없이 C를 준비했다. 원형 driver·DB를 보존했다.
- P3 제거 뒤 capture 검사는 첫 임시 run을 종료하지 않아 다음 capture가 기존 동시 실행 보호에 막혔다. 실패 driver와 영수증을 보존하고 의도적 capture를 종료 처리해 모델 없이 8개 입력을 재검증했다. 첫 capture 1회도 숨기지 않았다.
- 이번에 적재한 Qwen만 내려 `ollama ps` 빈 목록으로 자원을 반환했다. Ollama daemon과 기존 API 서버 3개의 PID 생존을 확인했으며 다른 프로세스 종료 동작은 0회이다.

[구조화 결과](document_graph_rag_continuation_20261013.json)에 모든 run ID·raw 위치·계약 SHA·단계별 비용·판정을 기록했다. [재현 안내와 manifest](document_graph_rag_continuation_20261013/README.md)에 동결 patch/driver·해시를 보존했다. DB·캐시·원본 전체는 커밋하지 않았다. clone만으로 모든 로컬 자료가 제공되는 묶음은 아니다.

## 남은 병목과 다음 후보

검색의 남은 문제는 후보 회수량 자체보다 **답변 내용과 적용 조건을 함께 최종 문맥에 남기는 선택 책임**이다. 관련 구간 일부를 늘리면 다른 자금의 조건이 밀릴 수 있다는 경계를 이번 P3에서 확인했다. 다음 후보는 원문의 자연스러운 근거 묶음으로 내용·대상·예외를 보존하는 방식이며 구현하거나 효과를 확인한 대안은 아니다. 정답 ID 할당으로 성공을 만들지 않는다.

답변에는 확보한 조건을 결론까지 보존하는 문제가 남는다. 원문 배열은 예외 귀속의 모순을 줄였지만 다른 필수 의미 누락을 막지 못했다. 근거에서 결론으로 이어지는 요청 포괄을 먼저 진단한 뒤 다음 변경을 고정해야 한다. 새 검수 모델·강화 프롬프트·재생성은 이번에 추가 승인하거나 실행하지 않았다. 현재 native 기준선 C의 원문 예산 문제는 의미 비교와 분리해 손실 없는 표현을 검토할 별도 후보다.

이번 제한 비교와 연구 보존은 완료하며 #660은 열어 둔다. 전체 26문항/A/전체 그래프·재추출/LH/UI·외부 모델·학습·병합·배포는 실행하지 않았다. 그래프 우위나 일반 정확성 개선을 주장하지 않는다. 현재 사용자 결정이 필요한 사항 없음.

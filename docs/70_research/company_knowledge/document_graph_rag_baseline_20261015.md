## 현재 상태와 역사적 기록의 경계

이전 문서의 137개 실행 시작·개념화0·전체26 미실행 등은 작성 시점의 사실이다. 2026-10-15 현재 중단 인계는 전역 개념화 응답 완료922(174재사용+748신규, 의미 정확성 검증 완료가 아님), 사용자 취소1, 미시도2699, 응답 완료 기준 잔여2700이다. 실재 프로세스는 종료됐고 원래 직렬화 상태 `cancel_requested`는 보존됐다. 사용자 취소는 의미 실패/품질 실패/추가 조정 회차가 아니다. 원래 최대6회 기록을 재설정하지 않는다. 이 PR은 중단 run을 재개하거나 새 B/C52답변·A26답변을 생성하지 않는다.

보존 스크립트9개와 prototype patch는 당시 재현 자료이며 이번 정적 검사는 이를 실행하지 않는다. Python AST와 JSON 파싱·파일 해시 확인은 모델 재실행·재채점·현재 품질 평가가 아니다. 역사적 점수는 해당 ledger의 범위·노출·방식·한계를 함께 읽는다.

## 공유 범위와 의존성

- 포함: 날짜별 설명, 질문·채점·비용 요약, 보존 manifest, 실행/입력/설정 식별자, 재현 스크립트 및 기각한 patch 기록.
- 로컬 전용: 원본 DB·대형 원시 응답/run payload·raw/frozen 모델 자료. 절대 경로와 hash는 당시 자료의 재현 위치이며 GitHub에서 열리는 파일을 보장하지 않는다.
- 이전 연구 스크립트는 해당 원래 제품 SHA와 로컬 보존 자료에 의존한다. main에서 일반 제품 스크립트처럼 바로 실행하도록 바꾸지 않았다.
- 미구현 pipeline 효율 계획2개는 로컬에 유지하고 이번 연구 baseline에 새 구현 계획으로 채택하지 않았다.
- #616/#617/#620/#660의 미완료 범위를 유지하며 자동 종료 문구를 사용하지 않는다. 새 실험·새 채점·모델 호출 없음.

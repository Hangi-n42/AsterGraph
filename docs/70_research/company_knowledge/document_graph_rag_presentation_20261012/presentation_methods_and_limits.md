# 발표 비교의 범위와 해석 기준

2026-10-12 발표를 위한 축소·탐색적 비교다. 아래는 실행 전 고정한 방법과 한계이며, 검색·답변 결과는 아직 기재하지 않았다.

- **비교 질문:** 같은 공식 원문과 질문에서 문서 Hybrid 검색(B)과 개념 포함 그래프 검색(C)이 필요한 근거와 답변을 얼마나 확보하는가?
- **공식 원문:** 중소벤처기업부 공고 제2018-447호의 창업기업자금 전체, 공통 규정, 명시적 참조 별표 1~11 및 16. 2019년의 모든 변경 공고나 현재 제도를 재현한 자료가 아니다.
- **동일한 검색 원문:** 3,364개 원문 블록, 45,124자에서 만든 3,371개 검색 구간이다. 그래프에 추출되지 않은 본문·표·별표도 B와 C의 검색 대상에 남긴다.
- **B:** BM25와 로컬 임베딩의 RRF 결합 → 공통 중복·문맥 처리 → 답변.
- **C:** 같은 원문에서 자동 추출한 관계·개념을 사용하는 그래프 검색 → 같은 공통 처리 → 같은 답변 모델. 관계 선택 모델과 순위 계산까지 포함한 경로 전체를 비교하며 그래프 연결만의 효과로 해석하지 않는다.
- **공통 조건:** 로컬 BGE-M3 임베딩, Qwen 답변, 근거 묶음 상한 12개, 원문 문맥 추정 토큰 상한 16,384. 실제 입력량을 억지로 같게 만들지 않는다. 필수 정답 근거를 강제로 넣지 않는다.
- **질문:** 실제 상담 2개, 원문 기반 보조 질문 4개. 단일 사실, 여러 근거 수집, 의존 판단, 자료 공백을 포함한다. 모두 탐색·계획 노출 이력을 보존하며 미사용 최종 확인셋이라고 부르지 않는다.
- **멀티홉 2개:** 하위 자금을 식별한 결과와 지출 항목을 결합하여 해당 자금의 제외 조건을 적용한다. 추론 연산 3개, 최대 의존 깊이 2단계다. 단순 문단 수집과 구분한다.

## 부분 구축임을 반드시 표시할 내용

이번 C는 **부분 구축 비상 비교**다. 기존 전체 실험의 완료 추출과 실패 기록을 보존한 뒤 별도 실행으로 이어 썼다. 선택 원문의 전체 그래프를 완성한 결과가 아니다.

- 재사용한 기존 추출 호출: 52회 중 실행 성공 46회, 출력 잘림 실패 6회. 실행 성공은 의미 정확성 판정과 다르다.
- 추가 개념화 대상: 개체·사건·관계 289개를 처리했다. 실제 모델 응답 288개, 사전 입력 예산 초과로 미호출 1개이며 미착수 대상은 없다. 성공한 개념도 미검수 상태다.
- 별표의 2,996개 원문 블록은 검색 풀에 포함되지만 추출은 하지 못했다.
- 관계 개념화 1개는 필수 원문·출력 예약·여유분을 합친 사전 예산 추정치(UTF-8 바이트/2 + 출력 + 1,000)가 98,825로 설정 문맥 49,152를 초과했다. 실제 제공자 입력 토큰 수가 아니며, 모델 호출 전에 제외됐다.
- 09:00 이후 새 개념화 호출을 시작하지 않는다. 13:00 이후 새 검색 관계 선택·답변 호출을 시작하지 않는다. 진행 중인 응답은 저장하고 이후 시도는 미실행으로 남긴다.
- 원래 전체 그래프, 원래 26개 최종 질문, 과거 상담 검색 A는 발표 이후 범위로 유보한다. 원래 전체 실험의 완료로 표시하지 않는다.

## 결과를 읽는 법

1. 검색은 순위표뿐 아니라 **답변 모델에 실제로 전달된 원문과 조건**으로 평가한다.
2. 답변은 필수 의미, 조건·예외, 인용의 지지, 구체적인 자료 공백을 원문·고정 참조와 대조한다. 표현만 다른 답은 인정한다.
3. 자료가 없다는 것과 현실에서 지원되지 않는다는 것을 구분한다. 질문하지 않은 부가 설명의 누락은 실패로 추가하지 않는다.
4. 계획한 6문항·12응답에서 실행 실패, 빈 응답, 미확정, 미실행을 숨기지 않는다. 실제 상담과 보조 문항은 따로 집계한다.
5. C에서 그래프를 실제 사용했는지와 dense fallback을 구분한다. 답변이 맞았다고 그래프 관계 자체도 정확하다고 판정하지 않는다.
6. 일부 개선은 인정하되 새 중대한 오류를 평균으로 숨기지 않는다. 작은 표본의 동률을 보편적 동등성으로 확대하지 않는다.
7. 재사용 추출의 이미 발생한 비용, 오늘 추가 개념화 비용, 질문별 검색·답변 비용을 분리한다. 호출 시간 합계와 전체 경과시간, 토큰 추정치와 제공자 실측치를 구분한다.

## 최종 자료에 넣을 항목

핵심 결과표 · 같은 질문의 근거/답변 비교 1건 · 실패 또는 미확인 사례 1건 · 구축/질의 비용 · 발표 가능한 결론과 아직 입증하지 못한 것.

참조 정답은 GPT-6 Astra의 별도 작성·검토 에이전트 기록을 사용한다. 같은 모델의 별도 에이전트 검토이며 사람 정답셋이나 서로 다른 모델의 검증으로 확대하지 않는다. 제품 출력은 추가 외부 모델 채점에 보내지 않고 조율 세션에서 고정 원문·참조와 직접 대조한다.

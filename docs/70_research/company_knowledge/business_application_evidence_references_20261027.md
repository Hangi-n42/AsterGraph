# 새 적용성 근거의 R 참조 전달 실험: 용량 해결, 기본 채택 보류

## 진행 이유와 범위

PR #674의 기준 HEAD `768c9640519abcfbf3dcb957975c120bada8ca64`에서 실제 적용성 1회는 완료됐지만, 그 결과로 만든 고정 R은 예약 포함 66,719토큰으로 49,152 한도를 초과해 전송하지 못했다. 같은 1,272자 원문이 참고 7의미 × 요청 3항목에서 21회 반복됐다.

완료 적용성 unit `1edc8dda85084947b9df0a4d1960ccfc`를 재사용하고, 신규 적용성 evidence의 모델 전달 표현만 바꿨다. 원래 통합 작업트리·코드·DB·실행 기록은 보존하고 별도 `codex/applicability-evidence-wire` 브랜치에서 작업했다. **이번 패치는 PR #674의 기본 제품 diff에 포함하지 않는다.**

수정 위치는 `business_run.json_request`/`json_call`이다. R의 `requirement_applications`와 `required_content_targets`에 있는 evidence만 기존 `reference_source_facts`의 정확 block 참조로 전달한다. 기존 원문 E evidence, 후보 raw/해석, 자기원문 검수, 교정 문맥, 판정 기준, 출력 스키마는 그대로다. 미채택 상태인 일반 R 전체 참조 압축을 재도입하지 않았다.

입력 계약은 `application-evidence-block-refs-v2`이다. 각 항목·대상의 관계와 이유·순서를 유지하고, 원문 주소를 가리키는 `evidence_ref + 절대 span`과 원래 `precision` 등 부가정보를 함께 전달한다. 상세 원형은 unit bindings에 보존한다. 기존 공개원문 경로의 기본 동작은 바꾸지 않는다. 예약 키 `evidence_ref`/`span`으로 새 주소를 덮어쓰려는 원형은 새 연결에서 거부한다. 미대응 인용을 참조로 정상화하지 않고 원형으로 유지한다.

## 핵심 의미 실패와 코드 차단의 경계

모델은 필요한 레시피 지정 부위가 표현됐다고 반환했다. 실제 기여로 선택한 `c10`에는 `raw.Head='찌개가 싱거우면'`, `raw.Tail='간장이나 소금으로 간을 한다.'`가 있을 뿐이다. 실제 raw/interpretation 표현 필드에는 등심이 없다. 모델은 원문의 등심과 간 맞추기 단계가 같은 레시피 의미 묶음에 있다는 이유로 필수 부위 표현까지 충족한 것으로 간주했다.

| 경로 | 원시 결과 | 제품 소비 결과 |
|---|---|---|
| whole recipe/한돈데이 맥락/부위 용도 | represented와 명시적 부족함이 공존하는 3건 | 기존 모순 guard가 unknown으로 남기고 원형/잔여 보존 |
| required recipe | represented, c10, 실제 간 맞추기 인용, missing_content='' | scope·실제 필드 주소 검사는 통과하여 represented로 소비 |
| 두 상품 required 행 | 이 후보 묶음에서 missing 2건 | 정상적인 국소 미발견. 전역 누락·새 교정 성공 아님 |

주소 결속 성공은 필수 내용에 대한 의미 지지의 증거가 아니다. 이번 저장 응답은 그 차이를 재현했다. consumer의 required row를 수동으로 unknown으로 고치지 않았고, 별도 평가 기록에서 잘못된 성공 판정임을 표시했다. 전체 completion은 partial이며 새 승인·교정·전체 M03 충족은 없다.

dependencies는 행 없이 `[]`로 반환됐다. 새 근거 없는 AND 제안은 없었지만 기존 source 전제를 보존한 것이며 독립성의 새 판정은 아니다. 간장 OR 소금의 실제 문구, 한돈데이 기여, 평균 생산량 4개, 구이용 기여는 남았다. 출하체중 예외와 기존 unverified obligation은 입력·DB에 보존됐고 새 모델이 예외를 부정하지는 않았으나, 예외/obligation의 의미 타당성을 새로 승인한 결과는 아니다. 끓음/후속 시점·상품 보관의 실제 저장 본문은 이 7개 범위에서 검증하지 않았다.

기존 원문 인용/부분 기여를 전체 표현으로 승격하는 오류가 새 필수부분 판정에서도 지속됐다. 이전 전체 PR674 R이 미실행이므로 참조 형식이 이 오류를 유발했다고 인과 판정하지 않는다. **중복 전달·완전 복원·용량 해결은 확인했고, 필수 내용의 실제 저장 표현 판정은 실패했다. 기본 채택은 보류한다.**

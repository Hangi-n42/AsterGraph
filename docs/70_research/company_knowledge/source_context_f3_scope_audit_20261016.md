## 원문과 task 보존 검증

선택695개에서 실제 target/선택 이웃 claim의 근거, 머리글5열, 전체 품목 행, 겹치는 병합 부모, section의 제목·표 밖 조건·주석, 다른 section의 기존 원문을 대조했다. 구조 보존 실패는0개이며 task 본문·실제 neighbor ID·해석 입력은 전후 동일하다. 유지/추가/제외 위치와 이유는 target별 기록과 원문 주소 catalog에 남겼다. 명시 참조 표식 검사와 DOM 포함 관계는 의미상 적용성 또는 문서 전체의 조건·예외 완결을 보장하지 않는다.

최종 근거 검증은 **실제 source packet의 본문과 모든 제공 구간의 합집합**을 사용한다. target별 중복을 제거한 근거 검사의 누적23,828개가 전후 모두 제공됐다. 물리적으로 서로 다른23,828개 블록이라는 뜻은 아니다. 최초 감사 도구가 같은 블록의 마지막 span만 남겨 whole 유지19개에서 잘못 누락 표시했다. v1은 보존하고, 실제 chunk 표시와 후보 payload 해시까지 확인한 `coverage_v3`로 보정했다. 중간 v2의 표시 재구성은 해시 guard에서 중단되어 결과를 내지 않았다. 제품·DB·모델 입력을 바꾸어 통과시킨 것이 아니다.

## 후속 두 생성의 사전 고정

조율 후 나노촉매와 고령친화 의료의 산업용 로봇 제조업만 F3 생성 각1회를 승인했다. 원문 증가297개와 원래 식별 미확정87개는 이번 생성에서 제외했고 삭제하지 않았다. 원문·실제 target/이웃·기존 판단 task·제품 프롬프트·모델 옵션·평가 기준을 생성 전에 고정했다. 예상 태그나 정답은 제품 입력에 넣지 않았다.

각 대상의 whole exact-message 완료 응답을 재호출하지 않고 평가 대조군으로 읽는다. 과거에 기록된 모델/digest·요청 한도·temperature·timeout 일치는 확인했지만 과거 엔진 버전·정밀도·실효 defaults·cache는 미상으로 남긴다. 새 실행의 runtime은 별도로 기록한다. 평가 기준은 품목/소재 또는 업종/제조 활동 핵심, 정확한 품목·행·테마 연결, 다른 동명 조건 혼입, 조건부 해당을 확정 자격으로 바꾸는 오류, 정상 개념의 소실이다. 짧은 관련 태그 각각에 모든 조건을 반복하도록 요구하지 않는다. 형식 성공·주소 보존과 의미 검토를 나눈다.

기존 Digital/무선2개 생성과 NAV01은 저장된 실제 증거로만 활용하며 재실행하지 않는다. 새 QA·임베딩·전체 graph 재구축은 하지 않는다. 실패/회귀가 나오면 그대로 기록하고 프롬프트 변경·반복 없이 제한 채택 유지 또는 새 범위 기각을 검토한다. 기존 실패 max6 계보를 계승하며 새6회 예산을 만들지 않는다.

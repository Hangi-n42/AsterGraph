# 문서 RAG와 지식 그래프 RAG: 발표용 실제 비교

2026-10-12 · 제한된 업무 범위의 탐색적 비교 · **부분 구축 그래프를 사용한 비상 비교**

## 발표에서 먼저 말할 결론

**같은 공식 원문과 6개 질문으로 실제 비교한 결과, 완전 충족 답변은 문서 Hybrid B와 개념 그래프 C 모두 4개였다. 이번 비교에서는 C의 추가 품질 이익을 확인하지 못했다.** C는 실제 그래프를 사용했지만, 한 질문에서 예외 적용 오류가 추가됐다. 다른 질문에서는 금리 설명이 개선된 대신 신청 자격을 잘못 결합해 단일 우열을 정하지 않았다.

이는 그래프 방식 전체가 무용하다는 결론이 아니다. **현재 부분 구축 그래프와 검색·관계 선택·답변 경로를 합친 결과**다. 자료와 모델을 고정했어도 그래프 연결 구조만의 순수 효과를 분리한 실험은 아니다.

## 무엇을 비교했나

- 공식 자료: 중소벤처기업부 공고 제2018-447호의 창업기업자금 전체와 공통 규정·참조 별표 1~11 및 16. 2019년 당시 모든 개정이나 현재 제도를 재현하지 않는다.
- B: 전체 축소 원문 풀 → BM25·로컬 임베딩 RRF Hybrid → 공통 문맥 처리 → 답변.
- C: 동일 원문에서 자동 추출·개념화한 그래프 검색 → 같은 공통 처리 → 같은 답변 모델.
- 공통 검색 풀: 원문 3,364블록·45,124자, 검색 구간 3,371개. 그래프에 추출되지 않은 표·별표와 문단 나머지도 양쪽에 보존했다.
- 실제 상담 2개와 원문 기반 보조 질문 4개. 모두 계획·참조 작성 노출을 기록한 탐색 문항이다. 미사용 최종 평가셋이나 실제 사용자 질문 분포로 주장하지 않는다.
- 답변 모델 `qwen3.8:27b-q4_K_M`, 로컬 BGE-M3 임베딩. 최종 근거 묶음 상한 12, 원문 입력 예산 추정 상한 16,384, temperature 0, thinking 비활성, 재시도 0. 실제 토큰 수는 억지로 같게 하지 않았다.
- 평가 정답·필수 근거·연결 경로는 구축 및 검색 입력에 주지 않았다. B/C 순서를 문항별로 교차했다. 실제 제품 서비스 진입점으로 실행했다.

## 핵심 결과표

‘근거’는 검색 순위에 있었는지가 아니라 **답변 모델에 실제로 전달된 필수 원문 의미**다. 괄호 안 숫자는 완전히 확보한 의미 수다. 단순 인용 개수가 아니다.

- **전체 6문항:** B 충족 4·부분 1·불충족 1 / C 충족 4·부분 0·불충족 2.
- **대응 비교:** C 개선 0·동일 4·악화 1·득실 혼재 1. 혼재는 개별 채점 불확실성이 아니라 서로 다른 의미에서 개선과 회귀가 함께 나온 경우다.
- **실행:** 계획 12응답, 저장 12, 빈 응답·실행 실패·미실행 0. 개별 채점 미확정 0.
- **검색:** 양쪽 모두 필수 의미 12개 중 완전 확보 11·부분 확보 1. 질문 단위 필수 근거 전체 확보는 각각 5/6.
- **답변 의미:** 양쪽 모두 12개 중 완전 충족 8·부분 1·미충족 3. 이 수가 같아도 새 범위 오류까지 같다는 뜻은 아니다. 위의 질문 상태와 중대한 오류를 함께 봐야 한다.
- **실제 상담만:** 양쪽 1/2 충족. **보조 질문만:** 양쪽 3/4 충족. 합계를 일반 정확도로 확대하지 않는다.
- **멀티홉만:** 양쪽 1/2 충족. 실패한 SUP02는 필수 근거를 확보한 뒤 예외를 연결·해석하는 단계에서 실패했다. 두 문항은 의존 깊이 2단계이며 3단계 연쇄 추론을 검증한 것은 아니다.
- **C 그래프 사용:** 5/6에서 선택 관계를 이용한 그래프 전파를 실행했다. SUP04는 선택 관계·seed가 0개여서 `dense_passages`로 전환됐다. C의 충족 4개 중 SUP04의 정답은 그래프 기여를 확인한 성과가 아니다. 답변의 정답 여부와 그래프 관계 자체의 의미 정확성도 별도다.

## 같은 질문의 비교 사례: 근거를 더 찾는 것만으로 해결되지 않은 경우

**질문 ACT501070:** 특허를 보유한 제조 창업기업이 개발기술사업화자금의 ①과 ②를 모두 충족해야 하는지, 다른 시설·운전자금은 무엇인지 문의했다.

원문은 ① 등록 특허 등을 사업화하려는 기업(P382~391)과 ② 인증 기업 등이 자체 기술을 사업화하는 경로(P392)를 구분한다. ① 경로에 ② 인증을 추가로 모두 요구하지 않는다. 실제 승인 여부는 별도 조건·심사 사항이다. 개발기술사업화자금의 금리는 별도 기준금리 규정(P417)이 있다.

| 확인 지점 | B 실제 결과 | C 실제 결과 |
|---|---|---|
| ①·② 신청 경로 | 필요한 원문을 받고도 “AND/OR가 명시되지 않았다”며 답변 보류 | “①과②를 모두 충족해야 한다”며 인증 없는 질문자를 제외 가능성이 높다고 설명 |
| 해당 자금 금리 | 일반 조건의 0.3%p 차감을 해당 자금에 잘못 적용 | 해당 자금의 변동 기준금리를 정확히 안내 |
| 다른 자금 안내 | 혁신창업지원의 일반 시설·운전자금 근거 일부가 최종 입력에서 빠졌고 대안을 답하지 못함 | 동일하게 대안 근거 일부 누락·대안 안내 실패 |
| 일반 규정과 예외 | 지원 횟수 제한을 설명하면서 제공된 예외를 생략 | 시설자금 일반 범위와 개발기술사업화 제외를 ‘모순’으로 취급 |

**해석:** C에는 금리 설명의 국소 개선이 있었지만, 핵심 자격 안내에는 더 단정적인 오류가 추가됐다. 개선 하나를 이유로 C가 이겼다고 하거나, 오류가 있다는 이유로 금리 개선을 없던 일로 하지 않는다. 필요한 문구의 도달은 확인했지만, 문서 구조 표현과 모델 해석 중 어느 요인이 자격 결합 오류를 얼마나 유발했는지는 이번 비교로 분리하지 못했다.

## 대표 실패: 제외 조건의 대상이 바뀜

**질문 SUP02:** 대표자 39세 이하·업력 3년 미만 자금을 식별하고, 그 자금에서 특허 매입 비용을 투자자금으로 지원하는지 묻는다.

원문의 연결은 다음과 같다.

1. 해당 나이·업력 조건 → 청년전용창업자금(P368~369).
2. 무형자산 투자자금 → 특허 등 지식재산권 매입(P405~409).
3. 그 투자자금 범위에서 청년전용창업자금 제외(P410).

양쪽 답변 입력에는 투자자금 목록과 제외 문구가 있었다. B의 `b22`는 `q6` 투자자금 항목, C의 `b25`는 `q8` 투자자금 항목에 `supports_context_ids`로 연결돼 있었다.

- B는 연결 자체를 언급하면서도 어느 항목의 제외인지 명확하지 않다며 지원 여부를 보류했다.
- C는 제외 문구를 **자가 사업장 확보자금**에 붙이고, 투자자금에는 포함·제외 근거가 없다고 답했다.

**확인된 실패 위치는 근거 확보 이후의 적용 범위 해석이다.** 그래프 경로를 사용했다는 사실이 예외의 올바른 적용을 보장하지 않았다. 이번 발표 비교 중에는 프롬프트를 고치거나 정답이 나올 때까지 재실행하지 않았다.

대조적으로 SUP01은 양쪽 모두 개발기술사업화자금의 임차보증금 제외를 올바르게 적용했다. 직접 선택 구간은 달랐지만 공통 문맥 처리 후 전달된 원문 텍스트 집합은 33개로 같았다. 이것은 공통 문맥 처리 이후 그래프의 추가 이익이 없었던 관찰이며 모든 질문에서 같다는 뜻은 아니다.

## 비용: 구축과 질의를 분리

토큰은 제공자가 보고한 실측값이다. 시간은 해당 호출들의 경과시간 합계이며 서로 겹치는 검색·색인·모델 시간을 다시 더하지 않는다. 금전·전력·사람 작업시간은 측정하지 않았다.

|---|---:|---:|---:|---|
| 이번 범위에 재사용한 기존 추출 | 52 | 204,057 / 166,216 | 12,901.61초 · 3시간35분2초 | 정상 응답46, 출력 잘림6 포함. 이미 발생한 비용이며 오늘 재호출하지 않음 |
| 추가 개념화 | 288 | 1,314,131 / 5,138 | 11,445.55초 · 3시간10분46초 | 추가 1대상은 사전 예산 초과로 실제 호출하지 못함 |

각 질의의 전체 wall time 합계는 B **598.58초**, C **623.27초**다. 실제 12개 run의 시작~종료는 **08:28:32~08:49:08 KST, 약 20분36초**였다. 최초 B에 공통 passage 임베딩 3,371개 생성 **82.41초**, 최초 C에 C 전용 edge 임베딩 1,446개 생성 **15.49초**가 포함됐다. C는 B가 먼저 만든 공통 색인을 재사용했다. 이 초기화 차이를 무시해 원시 시간만으로 속도 우위를 주장하지 않는다. 초기화 시간을 빼 만든 값도 별도로 다시 측정한 warm latency가 아니다.

C의 관계 선택만 6호출·입력 12,640/출력 410토큰·91.41초, 답변은 6호출·입력 33,463/출력 1,453토큰·262.95초였다. 이번 질의들에서는 추가 호출·입력 비용에 상응하는 명확한 질문 단위 품질 이익을 확인하지 못했다. 재사용 추출·추가 개념화 비용을 전체 공고 완성 비용으로 해석해서도 안 된다. 신규 개념화 run의 실제 경과시간은 05:14:51~08:28:10 KST, 약 3시간13분19초다.

## 무엇이 완료됐고 무엇이 남았나

**완료:** 기존 전체 실행을 보존하고 별도 부분 스냅샷으로 연결, B/C 공통 원문 풀 유지, 개념화 응답 288개 확보, 고정 질문 6쌍 실제 실행, 원문·고정 참조 대조, 비용·사례·실패 위치 정리.

**그래프의 한계:** 재사용 추출의 잘림 6건과 별표 2,996블록의 미추출이 남았다. 개념화 대상 289개 중 1개는 같은 관계 라벨에 연결된 필수 원문을 묶는 입력의 사전 예산 추정이 98,825로 설정 문맥 49,152를 넘어 호출되지 않았다. 이는 실제 모델 입력 토큰 초과나 의미 오판으로 계산하지 않는다. 성공 응답도 의미 승인된 온톨로지가 아니다.

**평가의 한계:** 고정 자료 하나·노출된 탐색 문항 6개·각 방식 1회 결과다. 참조 기준은 GPT-6 Astra 별도 작성·검토 에이전트의 원문 대조를 사용했다. 같은 모델의 별도 문맥이며 인간 정답셋이나 서로 다른 모델의 검증은 아니다. 제품 출력은 별도 외부 모델 채점에 보내지 않고 조율 세션이 원문·고정 기준과 대조했다. 출제·검토의 사용량/시간은 이번 제품 호출 비용에 포함하지 않았으며 별도 실측 미확인이다.

**이번 결과로 주장하지 않는 것:** 자동 의미 판단·부분 교정의 해결, 버스 변경 대응 효과, 승인 온톨로지의 정확성, 그래프의 보편적 열위, 모든 기업에서의 성능, 사람 총작업시간 절감, 2019년 상담 당시 모든 법령의 완전 재현.

**채택 판단:** 이번 범위에서 C를 품질 우위 때문에 기본으로 채택할 근거는 확보하지 못했다. C는 연구 경로로 보존하고, 답변 오류가 남은 B도 무검토 업무 판단용으로 검증됐다고 하지 않는다. 현재 제품 기본 경로를 이번 소표본만으로 자동 교체하지 않았다.

## 진행 이유와 구현 범위

실제 D01·부산 저장 결과를 발표 화면에서 읽을 수 있도록 그래프 배치, 글자, 관계선, 상세 패널을 개선했다. 기존 저장 ID·방향·평행 관계·상태·필터·수정 계약을 유지하는 프런트엔드 변경이다. 자동 추출의 의미 품질을 개선하거나 승인한 작업은 아니다.

Cytoscape.js 3.33.1의 Canvas 렌더러는 유지하고 배치에 `cytoscape-fcose` 2.2.0(MIT)을 추가했다. 타입 패키지는 2.2.5로 고정했다. 기존 격자보다 연결 구조를 드러내고, 확장 시 기존 위치를 초기값으로 쓰면서 중심 대상을 고정할 수 있어 선택했다. 다른 배치 엔진과의 정량 비교는 수행하지 않았다. 지원 옵션은 [fCoSE 공식 문서](https://github.com/iVis-at-Bilkent/cytoscape.js-fcose), 관계선 표시는 [Cytoscape 공식 문서](https://js.cytoscape.org/#style/edge-line)에 근거한다.

- 대상·업무 내용의 모양과 색을 구분하고 중심·선택·주변 연결을 강조한다. 평행 관계는 서로 다른 ID의 곡선으로 표시한다.
- 관계 이름은 선택·마우스 오버·소수 주변 연결에서 표시한다. 대상 이름 26자, 업무 문장 48자를 넘으면 캔버스에서만 줄이고 전체 이름은 상세·동일 그래프 목록에 남긴다.
- 집중 보기는 자료 버전과 실제 상태를 상단에 유지하며 그래프와 상세가 화면 높이를 사용한다. 상세를 닫거나 열 때 확대 비율을 유지한다.
- 이웃 확장은 기존 카메라 위치와 확대를 유지한다. 새 노드가 화면 밖에 있으면 사용자가 `화면 맞춤`으로 전체를 볼 수 있다. 단순 선택은 재배치하지 않는다.
- 여러 주장에 연결된 대상은 관계 목록과 주장 요약을 먼저 보여 주고 펼친 주장만 원문 DOM을 만든다. 단일 관계의 조건·예외·원문은 바로 표시한다.
- 명시적으로 `absent`인 해석 필드만 묶어 접는다. `unknown`은 미확인으로 남고, 실제 수락·미검수 상태를 보존한다. 범위 배지는 API의 `data_label`을 표시한다.
- 캔버스 포인터 선택은 화면 초점을 강제로 옮기지 않는다. 동일 그래프 목록의 키보드 선택은 상세 제목으로 초점을 옮긴다.

- DB·원문·원시 응답·캡처는 Git에 포함하지 않는다. PR 생성·병합·배포는 수행하지 않는다.

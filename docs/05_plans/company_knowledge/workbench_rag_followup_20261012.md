2026-10-12 · 조율: 계획 및 구상 · 상태: 실행 중

## 목적과 기존 완료 범위

UI의 실제 사용 버전·검토 상태를 조회 계약에 연결하고 기존 실제 변경 결과를 추적한다. 파이프라인은 ACT501070의 대안 자금 근거 누락과 SUP02의 예외 적용 오류를 서로 다른 원인으로 확인·수정한다. 기존 결과를 덮어쓰지 않으며, 효과가 없으면 기각 결과와 미완료 의미를 남긴다.

기준 관찰: UI `d10437bf` (`codex/knowledge-workbench-ui`), RAG `be543a89` (`feature/document-graph-rag-comparison`, 과거 실제 실행 코드 `da9f53ab`). 시작 때 각 작업 세션이 HEAD·변경·프로세스를 다시 확인한다. #661/#662의 탐색·편집·시각 개선, #658의 제품 교정 연결, 발표 6쌍 비교는 재구현·재실행하지 않는다. 전체 #660/26문항/A/전체 그래프와 자동 의미 판단 연구는 이번에 재개하지 않는다.

## 최신 조사로 좁힌 변경

- U1: `source_graph`의 `explicit_query_only`와 일반 `knowledge_state.active_snapshot_id`는 별개다. 현재 요구 버전·원문 제한·기존 변경 후 제외 기록을 읽기 조회하고, 과거 저장 QA와 현재 상태를 구분한다. UI가 별도의 승인 또는 전역 사용가능 판정을 만들지 않는다.
- U2: 이전 서울 버스 변경과 저장 QA 두 건이 남은 `business_change_snapshot_20261010/qa-runtime.db`를 바이트 동일 복사했다. 원본 SHA256은 `b85204999c9069cd629eab8a322454d3886adaf2830cea2fe7baa112c9d1165f`다. 새 8014/3014 환경에서 순번 12 비영향, 순번 13 변경, 이전 버전 제한과 새 요구의 `partial`을 확인한다.
- P1: 생산설비와 일반 운전자금 본문은 공통 원문 풀에 존재하지만 B 순위 25/44, C 순위 20/45로 최종 12개 밖이다. 예산 초과나 추출 원문 누락이 확인된 원인은 아니다. 원 질문에 명시된 번호 요청만 그대로 나누어 기존 검색 순위를 공통 선택에 연결하는 한 버전을 비교한다. 정답 구간에 도달할 때까지 할당량을 사후 조정하지 않는다.
- P2: 예외 문구는 이미 투자자금 제목의 문맥 ID와 연결돼 있다. 원문 블록 345→346→347의 순서와 같은 목록 항목의 DOM 위치가 답변 전달 과정에서 빠지는 것은 확인했다. 해당 원래 위치 정보를 복원하되 해석한 예외 대상을 새로 주입하지 않는다. 이 복원이 답변을 개선하는지는 실제 SUP02 B/C 비교로 판단한다.

P1과 P2는 독립 입력 버전으로 비교한다. P1은 무모델 선택 대조 후 근거가 실제 도달할 때 같은 질문 QA를 실행한다. P2는 같은 선택 문맥에서 답변만 실행하고, 개선 신호가 있을 때 SUP01/SUP03 정상 대조를 확인한다. 코드 연결·검색 도달·정답 의미·비용은 각각 보고한다.

## 실행 순서와 고정 비교

1. 두 세션이 최신 코드·실제 저장 결과·기존 패치를 읽고 확인된 결함/가설/이미 해결된 항목을 보고한다. UI 읽기 연결과 파이프라인 원인 추적은 병행한다.
2. U1 상태 연결을 구현하고 U2 실자료를 복사해 전후/비영향을 검증한다. 조율자가 중간·최종 브라우저 화면을 확인한다.
3. P1은 원문 존재→검색 순위→문맥 선택→입력의 손실 지점을 먼저 확인한다. 의미 개선을 위한 모델 실행 전에 변경 요소·기준선·정상 대조·채택/중단 기준을 고정한다.
4. P2는 검색을 고정한 답변 경계에서 비교한다. 기존 항목별 답변·범위 구조화 실패를 재사용해 동일 지시 변형을 반복하지 않는다. P1 성공을 P2의 선행조건으로 만들지 않는다.
5. 효과가 확인된 변경만 제품 서비스에서 같은 질문에 연결한다. 공통 모듈을 바꾼 범위에 해당하는 정상 대조만 실행한다. 필요할 때 작은 결합 확인을 하고 전체 평가를 반복하지 않는다.

고정 항목: 원문 버전/질문 원문/평가 필수 의미/저장 후보·그래프/로컬 모델 tag·digest·설정/입출력 한도/재시도 정책/예산·후처리. 기존 실제 응답은 이 항목이 일치할 때만 기준선 또는 정확 재생으로 활용한다. 평가용 정답·관계·근거 목록은 제품 입력에 넣지 않는다. 모든 비교 문항은 개발 노출 사례로 표시한다.

P1은 필수 의미·조건의 실제 도달 및 잘못된 대상 혼입을, P2는 같은 근거에서의 결론·예외·부재 설명·정상 보존을 각각 기록한다. B/C 공통 후처리는 같은 조건으로 적용한다. 호출 수, 실제 입출력, 시간, cache/재생, 실패·미확정은 분리한다. 변경이 여러 요소에 걸치면 하나의 순수 효과로 설명하지 않는다.

## 채택·중단·보고

확인된 코드/주소/형식 결함은 해당 경계만 고쳐 검사한다. 실제 의미 오답을 원하는 답이 나올 때까지 반복하지 않는다. 개선이 없으면 기본 경로에 누적하지 않고 실패를 보존한다. 한 경로의 실패가 독립 경로를 자동 중단하지 않는다. 100% 일반 정확성을 요구하지 않되 정상 사례의 중대한 회귀를 평균으로 숨기지 않는다.

최종은 UI 실제 상태 일치/실제 변경 탐색, P1 검색 효과, P2 답변 효과, 결합 확인을 구분한다. 원본/동결 DB 보존, 변경 경계 검사, 코드·데이터·실행 식별자, 전후 화면/출력, 채택·기각과 잔여 병목을 남긴다. 관련 파일만 한국어 커밋→푸시→원격 SHA 확인하며 실제 완료 이슈만 종료한다. PR 병합·배포·외부 모델 호출·자체 학습은 하지 않는다. 현재 사용자 결정이 필요한 사항 없음.

## 2026-10-12 비교 후 결정

P1의 원문 번호 요청별 BM25 순위와 기존 순위를 교대로 선택한 고정 구성은 B/C 모두 두 누락 근거를 전달하지 못했다. 이 구성은 기각하고 실제 QA·결합 비교는 진행하지 않았다. 검색 누락은 미해결이다. 이 결과를 질문별 검색이나 그래프 검색 전체의 불가능으로 확대하지 않는다.

P2는 기존 검색 결과를 재사용한 실제 로컬 QA 6회를 수행했다. SUP02 B는 기존 부분 충족에서 투자자금 제외를 일관되게 답하는 결과로 개선됐다. C는 잘못된 예외 귀속을 바로잡았지만 같은 답변 안의 '확인 불가/제외된다' 모순이 남아 불충족에서 부분 충족으로만 인정한다. SUP01 B/C의 임차보증금 제외와 SUP03 B/C의 고정금리는 유지됐다. 원문 위치 전달은 제한 채택하며 자동 의미 판단 일반 성능, 그래프 구조 자체의 우위 또는 전체 질문의 완료로 보고하지 않는다. 원문·설정·답변과 비용은 RAG 후속 실행 기록에서 별도로 보존한다.

U1은 조율 세션의 실제 브라우저 대조에서 이전/새 snapshot의 사용 정책·현재 요구·변경 후 제외를 구분했다. U2 검증 중 관련 요구를 0건으로 보이는 조회 누락과 과거 QA의 빈 참조 정보로 인한 조회 실패를 발견해 기존 저장 연결을 사용하는 수정에 포함했다. 최종 U2 브라우저·보존·원격 반영 결과는 UI 작업 보고서에서 확정한다.
